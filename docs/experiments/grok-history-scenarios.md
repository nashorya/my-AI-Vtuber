# Grok 历史场景测试

这些场景取自 `audio_debug.log` 里的真实直播片段。每个提示词都按程序实际发给模型的顺序排列：角色设定、身份说明、Cortico 台本语法、输出协议、历史对话、当前模式的接话规则、本轮输入。规则文字是从当前分支的源码里直接提取的，和程序里一字不差。

**用法**

1. 每个场景新开一个 Grok 对话，把代码块整段粘进去。
2. 先把第一段里的「临时替代」换成你真正的角色提示词（config.json 里的 `llm.system_prompt`）；不换也能测，但语气会和直播时不同。
3. 对照下面的「期望」和「看什么」打分。

**说明**

- 网页版 Grok 没有系统消息，这里用【系统】/【使用者输入】/【你之前的回复】标出各部分的角色。如果用 API 测，可以按标记拆成 system / user / assistant 消息，效果更接近真实。
- 别名只写了「爵爵子」。如果你在配置里设了唤醒词，把「你的名字与别名」那一行改成一样的。
- 没有记忆、观众资料、PK 对手资料这些按场次变化的内容。
- 「当时」是日志里你原来那个模型的实际表现，方便对比。
