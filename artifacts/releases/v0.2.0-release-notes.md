# AIVTuber v0.2.0

Windows x64 API-ASR distribution.

## Highlights

- Added the WPF monitoring and configuration dashboard.
- Added safer runtime reconfiguration, lifecycle handling, and request-generation isolation.
- Added the in-process PNG avatar renderer with expressions, mouth states, blinking, stickers, and motion probes.
- Disabled continuous PNG avatar breathing and idle left-right sway for a stable idle pose.
- Hardened SQLite shutdown, ASR sidecar contracts, dependency locking, release verification, and secret scanning.

## Package Notes

- This is the lightweight API-ASR build. The optional embedded local-ASR Python runtime is not included.
- ASR defaults to the Aliyun API in `config.json.template`.
- Copy `config.json.template` to `config.json`, then enter your own API credentials.
- No real configuration, API keys, databases, logs, or model cache are included.
